# Neuron AI — Brand Assets

This directory houses the official brand identity assets for Neuron AI.

Expected file:
- `neuron.ico`: Windows multi-resolution icon (16x16, 32x32, 48x48, 256x256) used for the executable icon, desktop shortcut, and system tray.

Note:
When `neuron.ico` is placed here, PyInstaller and the desktop shell application will automatically adopt it. If absent, the application gracefully falls back to the native Windows desktop icon.
